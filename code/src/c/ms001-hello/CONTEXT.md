# code/src/c/ms001-hello/ — Hello, World, with a Contract

**Last Updated**: 27/09/2026

The first C exercise, and the proof that milestone MS001 (Toolchain ready) is met: it builds, tests,
sanitises, memchecks and analyses cleanly, so every gate the later exercises depend on is known to work.
It is deliberately more than `printf("Hello, world!\n")`. `greet()` writes into a buffer the caller owns
and sizes, so the program already meets the question that runs through all of C — who owns this memory,
and how big is it? — along with the answer the standard library gives: `snprintf` writes at most `len`
bytes, and its return value says when the text did not fit. The folder ships as a worked example; its
Rust twin is `code/src/rust/crates/ms001_hello/`.

## Learning objective

After this exercise the learner can build a multi-file C program with make, read and state a C
function's contract (inputs, return value, error cases), test that contract with `check.h` — including
the off-by-one boundary — and run the four gates (`test`, `san`, `memcheck`, `lint`) and read what each
one reports.

## The contract

`greet(buf, len, name)` writes `Hello, <name>!` into `buf` and returns the number of characters written,
not counting the terminating NUL.

| Call | Returns | Why |
| --- | --- | --- |
| `greet(buf, 32, "world")` | `13` | fits: 13 characters plus the NUL is 14 bytes |
| `greet(buf, 14, "world")` | `13` | fits exactly — the boundary |
| `greet(buf, 13, "world")` | `-1` | one byte short: `snprintf` truncated, `buf` holds `Hello, world` |
| `greet(buf, 0, "world")` | `-1` | no room even for the NUL |
| `greet(NULL, 32, "world")`, `greet(buf, 32, NULL)` | `-1` | nothing to write to, or nothing to write |

## Concepts practised

| Concept | Where it shows |
| --- | --- |
| Header and source split; include guards | `greet.h` declares, `greet.c` defines; `#ifndef GREET_H` |
| `size_t` for sizes, and the room a NUL needs | `len` counts bytes including the terminator |
| `snprintf` and truncation | the return value is the length the full text *would* have had |
| Error returns in C | `-1` for invalid input or truncation; the caller checks it |
| `argc` / `argv` | `main.c` picks `argv[1]` when it exists |
| Casts made visible by `-Wsign-compare` (enabled by `-Wextra`) | `(size_t)n` in `greet.c`: comparing a signed `int` with a `size_t` |
| Boundary testing | `test_greet.c` tests 14 bytes and 13 bytes — both sides of the line |
| Linux kernel coding style | tabs, function braces on their own line, `/* */` comments, SPDX tags |
