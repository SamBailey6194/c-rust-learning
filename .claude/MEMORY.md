Read this at the start of every session, straight after `.claude/CLAUDE.md`. Write here instead
of the global auto-memory system, so what is learned lives in the repository and syncs with it.

**Project Patterns** (conventions discovered during work) · **Project State** (current phase and
milestone, toolchain facts and anything else not derivable from the repository itself)

`### <what was learned> — DD/MM/YYYY`. Keep entries concise — one paragraph max. Update or
remove stale entries rather than appending contradictions.

`DEFERRED.md`; live session continuity → a handoff in `handoffs/`. The three registers never
cross (`.claude/CLAUDE.md` Section 7).
